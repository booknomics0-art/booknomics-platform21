## Changes in this sprint
1. Rewrote meta titles and descriptions for the 20 priority books around actual GSC intent.
2. Merged GSC query variants into each book's `seo_keywords` without deleting existing keywords.
3. Added the legacy `बीजक-कबीर-saransh` slug to the canonical बीजक record for fallback canonical routing.
4. Reworked visible Hindi FAQs to answer author / “किसकी रचना” / work-type / summary intent from verified book metadata.
5. Added regression tests for the FAQ intent wording.

## Evaluation rule
Do not judge this sprint from live 24-hour partial GSC data. Compare settled 14-day data after deployment against this baseline. Primary targets: higher CTR on the priority pages and movement from positions ~6–9 toward positions ~3–6. Do not repeatedly rewrite titles during the observation window unless there is a technical error.
