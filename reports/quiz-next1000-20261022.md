## Creation method and limitations

No Gemini, Lovable, or other external **AI-generation API** was called. The questions were generated by an offline deterministic source-composition workflow that matched each book's existing `key_ideas` passages to concepts, generated multiple-choice options from other passages in that same book, and compared source-supported claims.

**This was not a human-written or independently fact-checked set of 10,000 questions.** Evidence matches are against the current Booknomics summaries, not the original books. Some source summaries are generic, and such quizzes can test recognition of editorial labels rather than substantive book knowledge. Options might be easy, awkward, semantically overlapping, or inaccurate relative to an original edition even when they pass structure checks. The difficulty labels are assigned by position and do not themselves prove cognitive difficulty.

These records are **draft**, each flagged for editorial review; no universal publish action or website deployment occurred in this operation. `book_assets` may currently be publicly readable regardless of status, so do **not** assume draft means hidden. Before approving or showcasing these quizzes, conduct book-specific fact checking against primary material and browser-based quiz attempt/score testing.

## Non-destructive write safeguards

- Only existing `book_assets` rows with `status='draft'` and an empty `quiz_data` JSON array were modified.
- The previous 607 quiz-book records were not selected for the new write operation.
- The output is traceable using the `quiz_data[0].batch_id` marker, and each quiz records source excerpts.
